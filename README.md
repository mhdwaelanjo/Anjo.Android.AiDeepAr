[![NuGet Version](https://img.shields.io/nuget/v/Anjo.Android.AiDeepAr)](https://www.nuget.org/packages/Anjo.Android.AiDeepAr) [![GitHub License](https://img.shields.io/github/license/mhdwaelanjo/Anjo.Android.AiDeepAr)](https://github.com/mhdwaelanjo/Anjo.Android.AiDeepAr/blob/master/LICENSE)

DeepAR is an end-to-end framework for creating augmented reality (AR) applications and solutions. With a host of pre-built AR effects and the ability to create custom ones, DeepAR provides the flexibility and control needed to create immersive AR experiences for mobile, web and desktop.
Get started : https://docs.deepar.ai/deepar-sdk/platforms/android/overview/
